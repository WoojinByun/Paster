# Paster

macOS 메뉴바에 상주하는 클립보드 히스토리 앱. 복사한 텍스트 / 이미지 / 파일을 저장해 두고, 전역 단축키로 여는 패널에서 검색해 붙여넣습니다.

> 🚧 개발 중 — 첫 릴리스(v0.1.0) 전입니다.

## 주요 기능

- 텍스트 / 이미지 / 파일 복사 히스토리
- 검색 (한글 부분 문자열 검색 지원)
- Clipboard | Pinned 2칼럼 패널
- 자동 붙여넣기, 일반 텍스트로 붙여넣기
- 타입별 보관 기간 설정 + 매일 자동 정리
- 제외할 앱 지정, 비밀번호 관리자 등의 숨김(concealed) 항목은 저장하지 않음
- 로그인 시 자동 실행
- Sparkle 자동 업데이트

## 요구 사항

- macOS 15 이상

## 설치 (사용자용)

1. [GitHub Releases](https://github.com/WoojinByun/Paster/releases/latest)에서 최신 `Paster-x.y.z.zip` 을 내려받습니다.
2. 압축을 풀고 `Paster.app` 을 `/Applications` 로 옮깁니다.

### Gatekeeper

앱이 notarize 되어 있지 않아 첫 실행이 차단됩니다. macOS 15 이상에서는 우클릭 → 열기로 우회할 수 없습니다. 아래 둘 중 하나를 사용하세요.

1. 시스템 설정 → 개인정보 보호 및 보안 → 아래로 스크롤 → "그래도 열기"
2. 터미널에서:

   ```sh
   xattr -dr com.apple.quarantine /Applications/Paster.app
   ```

### 손쉬운 사용 권한

첫 실행 시 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용 에서 Paster 를 허용해 주세요.

자동 붙여넣기는 직전에 쓰던 앱으로 ⌘V 를 보내는 방식이라 이 권한이 필요합니다. 권한이 없으면 Enter 를 눌러도 복사만 됩니다.

### 업데이트

업데이트는 Sparkle 로 자동 전달되며, 업데이트 후에도 손쉬운 사용 권한은 유지됩니다.

## 사용법

기본 단축키는 `⌃⌥⌘V` 입니다 (설정에서 변경 가능). 메뉴바 아이콘 → `Paster 열기` 로도 열 수 있습니다.

### 포커스 이동

- 열면 검색창에 포커스가 갑니다.
- 검색창에서 ↓ → Clipboard 칼럼.
- 목록에서 ←/→ → 칼럼 전환 (Clipboard ↔ Pinned).
- 각 칼럼의 맨 위 항목에서 ↑ → 검색창.
- 왼쪽 칼럼에서 ←, 오른쪽 칼럼에서 → 는 아무 동작도 하지 않습니다.
- 검색창 안에서 ←/→ 는 커서 이동만 합니다.
- 목록 포커스 중 글자를 입력하면 검색창으로 돌아가 이어서 입력됩니다.
- 칼럼별 마지막 선택 위치를 기억합니다.
- Clipboard 칼럼에는 고정하지 않은 항목만 표시됩니다 (Pinned 와 중복 없음).

### 키 표

| 키 | 동작 |
|---|---|
| Enter / 더블클릭 | 붙여넣기 (서식 유지) |
| ⇧Enter | 일반 텍스트로 붙여넣기 |
| ⌘Enter | 복사만 |
| ⌘1~9 | 포커스 칼럼의 N번째 항목 붙여넣기 (검색창 포커스면 Clipboard 기준) |
| ⌘P | 고정 / 해제 (반대 칼럼으로 이동) |
| ⌥⌘↑ / ↓ | Pinned 순서 변경 |
| ⌘⌫ | 항목 삭제 |
| Esc | 검색어가 있으면 지우고, 없으면 패널 닫기 |
| ↓ / ↑ / ← / → | 포커스 이동 (위 규칙 참조) |

## 설정

- 보관 기간: 텍스트 / 이미지 / 파일 타입별 켬/끔 + 24시간 / 7일 / 1개월 / 3개월 (기본 3개월)
- 단축키
- 제외할 앱
- 로그인 시 실행
- 자동으로 업데이트 확인
- Clear All History: 고정하지 않은 항목만 삭제하며 Pinned 는 유지합니다 (확인 대화상자 표시)

## 개인정보

- 모든 데이터는 `~/Library/Application Support/Paster/` 에만 저장됩니다.
- Sparkle 의 업데이트 확인(GitHub) 외에는 어디로도 데이터를 보내지 않습니다.
- 비밀번호 관리자 등이 표시한 concealed / transient 항목은 저장하지 않습니다.
- 클립보드 내용은 로그에 남기지 않습니다.
- 데이터 삭제: 설정의 Clear All History, 또는 위 폴더를 삭제하세요.

## 소스에서 빌드 (개발자용)

Xcode 16+ / Swift 6 필요. 아래 명령은 구현이 들어오면 사용할 수 있습니다 (구현 예정).

```sh
make cert      # 최초 1회: 자체 서명 인증서 "Paster Local Signing" 생성
make app       # build/Paster.app 빌드 + 서명
make install   # /Applications 로 복사
make test      # swift test
```

`make cert` 가 필요한 이유: ad-hoc 서명은 재빌드마다 서명이 달라져 손쉬운 사용 권한을 다시 요청하게 됩니다. 고정된 자체 서명 인증서로 서명하면 재빌드해도 권한이 유지됩니다.

## 릴리스 (메인테이너용)

```sh
make sparkle-keys             # 최초 1회: Sparkle EdDSA 키 생성
make release VERSION=x.y.z    # 빌드 · 서명 · zip · appcast 생성 · GitHub Release 업로드
```

> ⚠️ **반드시 백업하세요.**
> - "Paster Local Signing" 인증서: 키체인 접근에서 `.p12` 로 내보내기
> - Sparkle EdDSA 개인 키: `generate_keys -x <file>`
>
> 둘 중 하나라도 잃으면 업데이트가 깨지고, 사용자의 손쉬운 사용 권한이 초기화됩니다.

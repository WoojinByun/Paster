> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 플랜 1 의 `PasterCore` 위에 `Paster` 실행 타깃(메뉴바 앱: 클립보드 감시, 패널, 붙여넣기, 단축키, 정리 스케줄, 설정)을 만들고, 플랜 3 전에도 `make run` 으로 직접 실행해 수동 검증할 수 있게 한다.

**Architecture:** AppKit 생명주기(`@main` + `NSApplicationDelegate`, `.accessory` 정책)에 SwiftUI 화면을 `NSHostingView` 로 얹는다. 모든 UI 클래스는 `@MainActor` 이고, 무거운 캡처(이미지 변환 · DB 저장)만 `Task.detached` 로 순서대로 처리한다. 패널 키 입력은 `NSEvent.addLocalMonitorForEvents(matching: .keyDown)` 에서 `PanelKeyMapper` → `PanelReducer` 로 보내고, 반환된 `PanelEffect` 를 `PanelController` 가 실행한다. 검색창(NSTextField)은 패널이 열려 있는 동안 항상 first responder 이고, 목록 포커스는 리듀서 상태로만 표현한다 (한글 IME 조합이 끊기지 않게).

**Tech Stack:** Swift 6.4, AppKit, SwiftUI, Observation(`@Observable`), KeyboardShortcuts 3.1.0, ServiceManagement(`SMAppService`), ApplicationServices(`AXIsProcessTrusted`), CoreGraphics(`CGEvent`), PasterCore(플랜 1).

## 검증해 둔 사실

- **KeyboardShortcuts 3.1.0:** `KeyboardShortcuts.Name(_:default:)` 는 deprecated 이고 `init(_:initial:)` 로 바뀌었다. 그래서 `Self("togglePanel", initial: .init(.v, modifiers: [.control, .option, .command]))` 를 쓴다. `KeyboardShortcuts.Recorder("패널 열기", name: .togglePanel)`, `KeyboardShortcuts.onKeyUp(for:action:)` 는 그대로 있다. 최소 macOS 10.15 라 macOS 15 타깃과 맞는다.
- **리소스 번들:** `swift build` 는 `KeyboardShortcuts_KeyboardShortcuts.bundle`(지역화 문자열)과 `GRDB_GRDB.bundle` 을 bin 경로에 만든다. SwiftPM 이 생성한 `Bundle.module` 은 `Bundle.main.resourceURL`(= `Paster.app/Contents/Resources`)부터 찾고 못 찾으면 `fatalError` 를 낸다. 그러므로 `.app` 조립 시 `*.bundle` 을 `Contents/Resources/` 로 복사해야 한다 (Recorder 를 여는 순간 크래시 방지).
- **bin 경로:** 이 툴체인은 swiftbuild 백엔드라 실제 산출물이 `.build/out/Products/Debug` 에 있고 `.build/debug` 는 그 심볼릭 링크다. 스크립트는 경로를 하드코딩하지 않고 `swift build --show-bin-path` 를 쓴다.
- **Swift 6 동시성:**
  - `NSEvent.addLocalMonitorForEvents` 의 핸들러에서 `MainActor.assumeIsolated { ... return event }` 를 쓰면 `NSEvent` 가 Sendable 이 아니라 컴파일 오류가 난다. `@MainActor` 메서드 안에서 만든 (Sendable 이 아닌) 클로저는 메인 액터 격리를 물려받으므로 `assumeIsolated` 없이 바로 `self.handleKeyDown(event)` 를 부른다. 로컬 모니터는 메인 스레드에서 불린다.
  - `Task.detached` 안에서 메인 액터 프로퍼티인 클로저(`onSaved`)를 꺼내 부르면 오류(`non-Sendable type ... cannot exit main actor-isolated context`)가 난다. 메인 액터 메서드(`didSave()`)를 `await` 로 부른다.
  - `kAXTrustedCheckOptionPrompt` 는 전역 `var` 라 Swift 6 에서 직접 참조하면 동시성 오류가 난다. 같은 값인 문자열 `"AXTrustedCheckOptionPrompt"` 를 쓴다.
- 위 코드 전체는 이 툴체인에서 `swift build` 경고 0 으로 빌드됨을 확인했다. 실제 실행(GUI)은 확인하지 않았으므로 Task 7 의 수동 체크리스트로 검증한다.

```swift
        menu.addItem(open)

        menu.addItem(.separator())
```

```swift
import AppKit
import PasterCore

/// NSPasteboard → PasteboardSnapshot.
enum PasteboardReader {
    /// 건너뛸 표시가 있으면 내용은 읽지 않는다 (비밀번호 등).
    private static let skipMarkers: Set<String> = [
        PasteboardType.pasterInternal,
        PasteboardType.concealed,
        PasteboardType.transient,
        PasteboardType.autoGenerated,
    ]

    @MainActor
    static func snapshot(of pasteboard: NSPasteboard) -> PasteboardSnapshot {
        let types = pasteboard.pasteboardItems?.flatMap { $0.types.map(\.rawValue) } ?? []
        guard skipMarkers.isDisjoint(with: types) else {
            return PasteboardSnapshot(types: types)
        }
        let fileURLs = pasteboard.readObjects(
            forClasses: [NSURL.self],
            options: [.urlReadingFileURLsOnly: true]
        ) as? [URL] ?? []
        let string = pasteboard.string(forType: .string)
        var snapshot = PasteboardSnapshot(
            types: types,
            fileURLs: fileURLs,
            string: string,
            rtf: pasteboard.data(forType: .rtf),
            html: pasteboard.data(forType: .html)
        )
        // 이미지는 파일 · 텍스트가 없을 때만 읽는다 (TIFF 는 클 수 있다)
        if fileURLs.isEmpty, string?.isEmpty ?? true {
            snapshot.png = pasteboard.data(forType: .png)
            snapshot.tiff = snapshot.png == nil ? pasteboard.data(forType: .tiff) : nil
        }
        return snapshot
    }
}
```

`Sources/Paster/Clipboard/ClipboardMonitor.swift` — 타이머를 `.common` 모드에 넣어 메뉴가 열려 있어도 돈다. 저장 작업은 직전 작업을 `await` 해서 복사 순서대로 처리한다.

```swift
import AppKit
import PasterCore

/// changeCount 를 0.5초마다 확인하고, 바뀌면 캡처해 저장한다.
@MainActor
final class ClipboardMonitor {
    static let interval: TimeInterval = 0.5

    private let store: ClipStore
    private let settings: PasterSettings
    private let pasteboard: NSPasteboard
    private var lastChangeCount: Int
    private var timer: Timer?
    /// 저장을 순서대로 처리하기 위한 마지막 작업
    private var pending: Task<Void, Never>?

    var onSaved: (() -> Void)?

    init(store: ClipStore, settings: PasterSettings, pasteboard: NSPasteboard = .general) {
        self.store = store
        self.settings = settings
        self.pasteboard = pasteboard
        lastChangeCount = pasteboard.changeCount
    }

    func start() {
        let timer = Timer(timeInterval: Self.interval, repeats: true) { [weak self] _ in
            MainActor.assumeIsolated { self?.poll() }
        }
        timer.tolerance = 0.1
        // 메뉴가 열려 있는 동안에도 돌도록 common 모드에 넣는다
        RunLoop.main.add(timer, forMode: .common)
        self.timer = timer
    }

    func stop() {
        timer?.invalidate()
        timer = nil
    }

    private func poll() {
        let changeCount = pasteboard.changeCount
        guard changeCount != lastChangeCount else { return }
        lastChangeCount = changeCount

        let snapshot = PasteboardReader.snapshot(of: pasteboard)
        let frontmost = NSWorkspace.shared.frontmostApplication
        let source = SourceApp(bundleID: frontmost?.bundleIdentifier, name: frontmost?.localizedName)
        let capture = settings.makeCapture()
        let store = store
        let previous = pending
        pending = Task.detached(priority: .utility) { [weak self] in
            await previous?.value
            guard case let .captured(clip) = capture.capture(snapshot, source: source) else { return }
            do {
                try store.save(clip, now: Date())
            } catch {
                Log.capture.error("저장 실패: \(String(describing: error), privacy: .public)")
                return
            }
            await self?.didSave()
        }
    }

    private func didSave() {
        onSaved?()
    }
}
```

```swift
import AppKit
import PasterCore

/// 정리 시점 관리 (스펙 7.2절): 실행 시, 매일 0시, 잠자기에서 깬 뒤 날짜가 바뀌었을 때.
/// 시계 · 시간대가 바뀌면 0시 타이머를 다시 잡는다.
@MainActor
final class RetentionScheduler {
    private let service: RetentionService
    private let settings: PasterSettings
    private var timer: Timer?
    private var observers: [(NotificationCenter, NSObjectProtocol)] = []

    var onPurged: (() -> Void)?

    init(service: RetentionService, settings: PasterSettings) {
        self.service = service
        self.settings = settings
    }

    func start() {
        purge()
        scheduleMidnight()

        let workspaceCenter = NSWorkspace.shared.notificationCenter
        observe(workspaceCenter, NSWorkspace.didWakeNotification) { $0.didWake() }
        observe(.default, .NSSystemClockDidChange) { $0.clockDidChange() }
        observe(.default, .NSSystemTimeZoneDidChange) { $0.clockDidChange() }
    }

    private func observe(_ center: NotificationCenter, _ name: Notification.Name, _ handler: @escaping @MainActor (RetentionScheduler) -> Void) {
        let token = center.addObserver(forName: name, object: nil, queue: .main) { [weak self] _ in
            MainActor.assumeIsolated {
                guard let self else { return }
                handler(self)
            }
        }
        observers.append((center, token))
    }

    private func didWake() {
        do {
            if try service.purgeIfDayChanged(using: settings) != nil { onPurged?() }
        } catch {
            Log.retention.error("깨어난 뒤 정리 실패: \(String(describing: error), privacy: .public)")
        }
        // 잠든 사이 0시가 지났을 수 있으니 다시 잡는다
        scheduleMidnight()
    }

    private func clockDidChange() {
        NSTimeZone.resetSystemTimeZone()
        scheduleMidnight()
    }

    private func scheduleMidnight() {
        timer?.invalidate()
        let fireDate = RetentionSchedule.nextMidnight(after: Date(), calendar: .autoupdatingCurrent)
        let timer = Timer(fire: fireDate, interval: 0, repeats: false) { [weak self] _ in
            MainActor.assumeIsolated {
                self?.purge()
                self?.scheduleMidnight()
            }
        }
        RunLoop.main.add(timer, forMode: .common)
        self.timer = timer
        Log.retention.info("다음 정리: \(fireDate, privacy: .public)")
    }

    private func purge() {
        do {
            try service.purge(using: settings)
            onPurged?()
        } catch {
            Log.retention.error("정리 실패: \(String(describing: error), privacy: .public)")
        }
    }
}
```

```swift
import AppKit
import PasterCore
import UniformTypeIdentifiers

/// pasteboard 쓰기 → 직전 앱 활성화 → ⌘V (스펙 9절).
@MainActor
final class PasteService {
    enum WriteResult: Equatable {
        case written
        case missingFiles
        case missingImage
    }

    private let store: ClipStore
    private let pasteboard: NSPasteboard

    init(store: ClipStore, pasteboard: NSPasteboard = .general) {
        self.store = store
        self.pasteboard = pasteboard
    }

    /// pasteboard 에 쓰고 last_copied_at 을 갱신한다. 자체 마커를 붙여 Monitor 가 다시 캡처하지 않게 한다.
    func write(_ item: ClipItem, mode: PasteMode) -> WriteResult {
        let items: [NSPasteboardItem]
        switch item.kind {
        case .text:
            let entry = NSPasteboardItem()
            entry.setString(item.plainText, forType: .string)
            if mode != .plainText {
                if let rtf = item.rtf { entry.setData(rtf, forType: .rtf) }
                if let html = item.html { entry.setData(html, forType: .html) }
            }
            items = [entry]
        case .image:
            guard let name = item.imageBlob, let png = store.blobs.read(name) else { return .missingImage }
            let entry = NSPasteboardItem()
            entry.setData(png, forType: .png)
            if let tiff = ImageConverter.convert(png, to: .tiff) { entry.setData(tiff, forType: .tiff) }
            items = [entry]
        case .files:
            guard item.missingFilePaths().isEmpty else { return .missingFiles }
            if mode == .plainText {
                let entry = NSPasteboardItem()
                entry.setString(item.filePaths.joined(separator: "\n"), forType: .string)
                items = [entry]
            } else {
                items = item.filePaths.map { path in
                    let entry = NSPasteboardItem()
                    entry.setString(URL(fileURLWithPath: path).absoluteString, forType: .fileURL)
                    return entry
                }
            }
        }

        for entry in items {
            entry.setData(Data(), forType: NSPasteboard.PasteboardType(PasteboardType.pasterInternal))
        }
        pasteboard.clearContents()
        pasteboard.writeObjects(items)

        if let id = item.id {
            do {
                try store.touch(id: id, now: Date())
            } catch {
                Log.app.error("last_copied_at 갱신 실패: \(String(describing: error), privacy: .public)")
            }
        }
        return .written
    }

    /// 직전 앱을 활성화하고, 활성화가 끝나면 ⌘V 를 보낸다.
    /// 직전 앱이 없거나 활성화되지 않으면 ⌘V 를 보내지 않는다 (클립은 pasteboard 에 남는다).
    @discardableResult
    func activateAndPaste(into target: NSRunningApplication?) async -> Bool {
        guard let target, !target.isTerminated else {
            Log.app.info("직전 앱이 없어 ⌘V 를 건너뜀")
            return false
        }
        target.activate()
        let deadline = Date().addingTimeInterval(0.5)
        while NSWorkspace.shared.frontmostApplication?.processIdentifier != target.processIdentifier,
              Date() < deadline {
            try? await Task.sleep(for: .milliseconds(20))
        }
        guard NSWorkspace.shared.frontmostApplication?.processIdentifier == target.processIdentifier else {
            Log.app.info("직전 앱 활성화 시간 초과로 ⌘V 를 건너뜀")
            return false
        }
        // 활성화 직후 키 입력을 놓치지 않도록 잠깐 기다린다
        try? await Task.sleep(for: .milliseconds(50))
        Self.postCommandV()
        return true
    }

    private static func postCommandV() {
        let source = CGEventSource(stateID: .combinedSessionState)
        let virtualKeyV: CGKeyCode = 0x09
        let down = CGEvent(keyboardEventSource: source, virtualKey: virtualKeyV, keyDown: true)
        down?.flags = .maskCommand
        let up = CGEvent(keyboardEventSource: source, virtualKey: virtualKeyV, keyDown: false)
        up?.flags = .maskCommand
        down?.post(tap: .cghidEventTap)
        up?.post(tap: .cghidEventTap)
    }
}
```

  5. `PanelModel.send(key)` → 리듀서. effect 가 `.passThrough` 면 이벤트를 검색창으로 보내고, 아니면 소비(`nil` 반환)한다.
- 검색창은 항상 first responder 다. 목록 포커스는 리듀서 상태로만 그린다. 그래서 목록에서 글자를 치면 리듀서가 포커스를 검색창으로 옮기고(`.passThrough`) 같은 키 이벤트가 그대로 검색창에 들어가 IME 조합도 이어진다.
- 행: 출처 앱 아이콘 + (Pinned 면 📌) + 제목(`ClipItem.title`) + 원본 없는 파일 ⚠ + 포커스 칼럼(검색창 포커스면 Clipboard)에만 `⌘1`~`⌘9` 힌트. Pinned 가 비면 "⌘P로 고정".
- 미리보기 띠: 텍스트 전문(스크롤), 이미지 fit, 파일 전체 경로 + 존재 여부, 메타 줄 `출처 앱 · 상대 시각 · 크기`. 안내 메시지(원본 파일 없음 / 권한 없음 + "시스템 설정 열기" 버튼)도 여기에 표시.
- 붙여넣기: `.missingFiles` 면 패널을 닫지 않고 "원본 파일이 없습니다". ⌘Enter(복사만)는 쓰고 닫는다. 권한이 없으면 복사만 하고 패널에 안내. 권한이 있으면 패널을 닫고 직전 앱에 ⌘V.
- 단축키: 기본 ⌃⌥⌘V, `onKeyUp` 으로 토글.

```swift
        case .needsAccessibility: "손쉬운 사용 권한이 없어 복사만 했습니다. ⌘V 로 붙여넣으세요."

/// 패널 화면 상태. 키 처리는 PanelReducer 에 맡긴다.
@MainActor
@Observable
final class PanelModel {
    var state = PanelState()
    private(set) var clipboardItems: [ClipItem] = []
    private(set) var pinnedItems: [ClipItem] = []
    var message: PanelMessage?

    @ObservationIgnored private let store: ClipStore
    @ObservationIgnored private let settings: PasterSettings
    /// SearchField 가 만들어지면 자기 자신을 등록한다.
    @ObservationIgnored weak var searchField: NSTextField?
    /// 리듀서가 낸 effect 를 처리할 곳 (PanelController).
    @ObservationIgnored var effectHandler: ((PanelEffect) -> Void)?

    init(store: ClipStore, settings: PasterSettings) {
        self.store = store
        self.settings = settings
    }

    /// 패널을 열 때: 검색어 · 포커스 초기화.
    func resetForOpen() {
        state = PanelState()
        message = nil
        reload()
    }

    func reload() {
        do {
            clipboardItems = try store.fetchUnpinned(matching: state.query, settings: settings.retention, now: Date())
            pinnedItems = try store.fetchPinned(matching: state.query)
        } catch {
            Log.app.error("목록 읽기 실패: \(String(describing: error), privacy: .public)")
        }
        state.updateCounts(clipboard: clipboardItems.count, pinned: pinnedItems.count)
    }

    func queryChanged(_ query: String) {
        guard query != state.query else { return }
        state.setQuery(query)
        message = nil
        reload()
    }

    /// 키 · 클릭을 리듀서에 넣고 effect 를 넘긴다. 반환값은 키 이벤트를 흘려보낼지 판단하는 데 쓴다.
    @discardableResult
    func send(_ key: PanelKey) -> PanelEffect? {
        let (next, effect) = PanelReducer.reduce(state, key)
        let queryChanged = next.query != state.query
        state = next
        if queryChanged { reload() }
        if let effect, effect != .passThrough { effectHandler?(effect) }
        return effect
    }

    func item(_ column: PanelColumn, _ index: Int) -> ClipItem? {
        let items = column == .clipboard ? clipboardItems : pinnedItems
        return items.indices.contains(index) ? items[index] : nil
    }

    func items(in column: PanelColumn) -> [ClipItem] {
        column == .clipboard ? clipboardItems : pinnedItems
    }

    var previewItem: ClipItem? {
        state.activeIndex.flatMap { item(state.activeColumn, $0) }
    }

    func blobURL(for item: ClipItem) -> URL? {
        item.imageBlob.map { store.blobs.url(for: $0) }
    }
}
```

```swift
/// AppKit 검색창. 키 라우팅 중 동기적으로 first responder 를 다루기 위해 NSTextField 를 직접 쓴다.
struct SearchField: NSViewRepresentable {
    let model: PanelModel

    func makeNSView(context: Context) -> NSTextField {
        let field = FocusingTextField()
        field.placeholderString = "검색"
        field.isBordered = false
        field.drawsBackground = false
        field.focusRingType = .none
        field.font = .systemFont(ofSize: 18)
        field.delegate = context.coordinator
        field.cell?.usesSingleLineMode = true
        field.cell?.isScrollable = true
        model.searchField = field
        return field
    }

    func updateNSView(_ field: NSTextField, context: Context) {
        let query = model.state.query
        // IME 조합 중에는 건드리지 않는다
        if let editor = field.currentEditor() as? NSTextView, editor.hasMarkedText() { return }
        if field.stringValue != query { field.stringValue = query }
    }

    func makeCoordinator() -> Coordinator {
        Coordinator(model: model)
    }

    /// 창에 붙는 즉시 first responder 가 된다 (패널을 처음 열 때).
    final class FocusingTextField: NSTextField {
        override func viewDidMoveToWindow() {
            super.viewDidMoveToWindow()
            window?.makeFirstResponder(self)
        }
    }

    @MainActor
    final class Coordinator: NSObject, NSTextFieldDelegate {
        let model: PanelModel

        init(model: PanelModel) {
            self.model = model
        }

        func controlTextDidChange(_ notification: Notification) {
            guard let field = notification.object as? NSTextField else { return }
            model.queryChanged(field.stringValue)
        }
    }
```

```swift
import AppKit
import PasterCore
import SwiftUI

/// 패널 열기 / 닫기, 키 라우팅, effect 실행.
@MainActor
final class PanelController: NSObject, NSWindowDelegate {
    private let environment: AppEnvironment
    private let model: PanelModel
    private let pasteService: PasteService
    private lazy var panel: PasterPanel = makePanel()
    private var keyMonitor: Any?
    /// 패널을 열기 직전의 frontmost 앱. 붙여넣기 대상.
    private var previousApp: NSRunningApplication?

    init(environment: AppEnvironment) {
        self.environment = environment
        model = PanelModel(store: environment.store, settings: environment.settings)
        pasteService = PasteService(store: environment.store)
        super.init()
        model.effectHandler = { [weak self] effect in self?.perform(effect) }
    }

    var isVisible: Bool { panel.isVisible }

    func toggle() {
        isVisible ? close() : show()
    }

    func show() {
        let frontmost = NSWorkspace.shared.frontmostApplication
        if frontmost?.processIdentifier != ProcessInfo.processInfo.processIdentifier {
            previousApp = frontmost
        }
        model.resetForOpen()
        panel.centerOnMouseScreen()
        panel.makeKeyAndOrderFront(nil)
        // 처음 열 때는 SwiftUI 가 아직 검색창을 만들지 않았을 수 있어 먼저 배치한다
        panel.contentView?.layoutSubtreeIfNeeded()
        if let field = model.searchField { panel.makeFirstResponder(field) }
        installKeyMonitor()
    }

    func close() {
        removeKeyMonitor()
        panel.orderOut(nil)
    }

    func reloadIfVisible() {
        guard isVisible else { return }
        model.reload()
    }

    // MARK: NSWindowDelegate

    func windowDidResignKey(_ notification: Notification) {
        // 바깥을 클릭하면 닫는다
        close()
    }

    // MARK: 키 라우팅

    private func installKeyMonitor() {
        guard keyMonitor == nil else { return }
        // 로컬 모니터는 메인 스레드에서 불린다
        keyMonitor = NSEvent.addLocalMonitorForEvents(matching: .keyDown) { [weak self] event in
            guard let self else { return event }
            return self.handleKeyDown(event)
        }
    }

    private func removeKeyMonitor() {
        if let keyMonitor { NSEvent.removeMonitor(keyMonitor) }
        keyMonitor = nil
    }

    private func handleKeyDown(_ event: NSEvent) -> NSEvent? {
        guard event.window === panel else { return event }
        // 한글 등 IME 조합 중에는 검색창에 맡긴다
        if let editor = panel.fieldEditor(false, for: model.searchField) as? NSTextView, editor.hasMarkedText() {
            return event
        }
        let modifiers = KeyModifiers(event.modifierFlags)
        // 메인 메뉴가 없는 앱이라 ⌘C/⌘V 등 편집 단축키를 직접 보낸다
        if modifiers == .command, let action = Self.editAction(for: event.charactersIgnoringModifiers) {
            NSApp.sendAction(action, to: nil, from: nil)
            return nil
        }
        guard let key = PanelKeyMapper.key(
            keyCode: event.keyCode,
            modifiers: modifiers,
            characters: event.charactersIgnoringModifiers
        ) else { return event }

        let effect = model.send(key)
        if effect == .passThrough {
            // 검색창이 항상 first responder 이지만, 혹시 잃었으면 되돌린다
            if let field = model.searchField, panel.firstResponder !== field.currentEditor() {
                panel.makeFirstResponder(field)
            }
            return event
        }
        return nil
    }

    private static func editAction(for characters: String?) -> Selector? {
        switch characters?.lowercased() {
        case "x": #selector(NSText.cut(_:))
        case "c": #selector(NSText.copy(_:))
        case "v": #selector(NSText.paste(_:))
        case "a": #selector(NSText.selectAll(_:))
        case "z": Selector(("undo:"))
        default: nil
        }
    }

    // MARK: effect

    private func perform(_ effect: PanelEffect) {
        let store = environment.store
        do {
            switch effect {
            case .passThrough:
                return
            case .close:
                close()
            case let .paste(column, index, mode):
                guard let item = model.item(column, index) else { return }
                paste(item, mode: mode)
            case let .togglePin(column, index):
                guard let id = model.item(column, index)?.id else { return }
                if column == .clipboard {
                    try store.pin(id: id, now: Date())
                } else {
                    try store.unpin(id: id, now: Date())
                }
                model.reload()
            case let .movePinned(index, direction):
                guard let id = model.item(.pinned, index)?.id else { return }
                try store.movePinned(id: id, direction: direction)
                model.reload()
            case let .delete(column, index):
                guard let id = model.item(column, index)?.id else { return }
                try store.delete(id: id)
                model.reload()
            }
        } catch {
            Log.app.error("패널 동작 실패: \(String(describing: error), privacy: .public)")
        }
    }

    private func paste(_ item: ClipItem, mode: PasteMode) {
        switch pasteService.write(item, mode: mode) {
        case .missingFiles:
            model.message = .missingFiles
            return
        case .missingImage:
            model.message = .missingImage
            return
        case .written:
            break
        }
        if mode == .copyOnly {
            close()
            return
        }
        guard AccessibilityPermission.isTrusted else {
            model.message = .needsAccessibility
            model.reload()
            return
        }
        let target = previousApp
        close()
        Task { await pasteService.activateAndPaste(into: target) }
    }

    // MARK: 패널 생성

    private func makePanel() -> PasterPanel {
        let panel = PasterPanel()
        panel.delegate = self
        panel.contentView = NSHostingView(rootView: PanelView(model: model))
        return panel
    }
```

```swift
/// 제외 앱 목록의 한 줄.
struct ExcludedApp: Identifiable, Equatable {
    let bundleID: String
    let name: String
    var id: String { bundleID }
}

@MainActor
@Observable
final class SettingsModel {
    var retention: RetentionSettings {
        didSet {
            settings.retention = retention
            onDataChanged()
        }
    }
    private(set) var excludedApps: [ExcludedApp] = []
    private(set) var launchAtLogin: Bool
    var errorMessage: String?

    @ObservationIgnored private let settings: PasterSettings
    @ObservationIgnored private let store: ClipStore
    @ObservationIgnored private let onDataChanged: () -> Void

    init(environment: AppEnvironment, onDataChanged: @escaping () -> Void) {
        settings = environment.settings
        store = environment.store
        self.onDataChanged = onDataChanged
        retention = environment.settings.retention
        launchAtLogin = SMAppService.mainApp.status == .enabled
        reloadExcludedApps()
    }

    // MARK: 로그인 시 실행

    func setLaunchAtLogin(_ enabled: Bool) {
        do {
            if enabled {
                try SMAppService.mainApp.register()
            } else {
                try SMAppService.mainApp.unregister()
            }
            errorMessage = nil
        } catch {
            errorMessage = "로그인 시 실행 설정 실패: \(error.localizedDescription)"
        }
        launchAtLogin = SMAppService.mainApp.status == .enabled
    }

    // MARK: 제외 앱

    func addExcludedApp() {
        let panel = NSOpenPanel()
        panel.title = "제외할 앱 선택"
        panel.directoryURL = URL(fileURLWithPath: "/Applications")
        panel.allowedContentTypes = [.application]
        panel.allowsMultipleSelection = true
        guard panel.runModal() == .OK else { return }
        let ids = panel.urls.compactMap { Bundle(url: $0)?.bundleIdentifier }
        settings.excludedBundleIDs += ids
        reloadExcludedApps()
    }

    func removeExcludedApp(_ app: ExcludedApp) {
        settings.excludedBundleIDs = settings.excludedBundleIDs.filter { $0 != app.bundleID }
        reloadExcludedApps()
    }

    private func reloadExcludedApps() {
        excludedApps = settings.excludedBundleIDs.map { bundleID in
            let url = NSWorkspace.shared.urlForApplication(withBundleIdentifier: bundleID)
            let name = url.map { FileManager.default.displayName(atPath: $0.path) } ?? bundleID
            return ExcludedApp(bundleID: bundleID, name: name)
        }
    }

    // MARK: 전체 삭제

    func clearAllHistory() {
        do {
            let count = try store.deleteAllUnpinned()
            Log.app.info("전체 삭제: \(count, privacy: .public)건")
            onDataChanged()
        } catch {
            errorMessage = "삭제 실패: \(error.localizedDescription)"
        }
    }
}
```

- [ ] ⇧Enter → 일반 텍스트로 붙여넣기 (서식 없음).
- [ ] ⌘Enter → 붙여넣지 않고 패널만 닫힘, 이후 ⌘V 로 붙는다.
- [ ] ⌘3 → Clipboard 세 번째 항목 붙여넣기. Pinned 포커스에서 ⌘1 → Pinned 첫 항목.
- [ ] 이미지 Enter → TextEdit(RTFD 문서)에 이미지가 붙는다.
- [ ] 파일 Enter → Finder 창에서 붙이면 파일이 복사된다 / TextEdit 에서는 파일이 첨부된다.
- [ ] 원본 파일을 지운 뒤 그 항목에 ⚠ 가 보이고, Enter 하면 "원본 파일이 없습니다" 가 뜨고 패널이 열려 있다.
- [ ] 붙여넣은 항목이 Clipboard 맨 위로 올라온다 (`last_copied_at` 갱신). Paster 가 쓴 내용이 새 행으로 중복 저장되지 않는다 (자체 마커).
- [ ] 시스템 설정에서 Paster 의 손쉬운 사용 권한을 끄고 Enter → 복사만 되고 패널에 안내와 "시스템 설정 열기" 버튼. 버튼은 손쉬운 사용 화면을 연다.

패널 키 (스펙 8.3, 8.4절)
- [ ] 열면 검색창 포커스, ↓ → Clipboard, 맨 위에서 ↑ → 검색창.
- [ ] 검색창 안에서 ←/→ 는 커서만 움직인다.
- [ ] Clipboard 에서 ← 무동작, Pinned 에서 → 무동작.
- [ ] 목록 포커스에서 글자 입력 → 검색창에 이어서 입력 (한글 조합 포함).
- [ ] ⌘P → 반대 칼럼으로 이동. Pinned 에서 ⌘P → Clipboard 맨 위로 (해제 시각 now).
- [ ] ⌥⌘↑/↓ → Pinned 순서 변경, 패널을 다시 열어도 유지.
- [ ] ⌘⌫ → 항목 삭제 (이미지면 `blobs/` 파일도 사라짐).
- [ ] 더블클릭 → 붙여넣기.
- [ ] 검색: `체크리`(3글자 이상, 한글 부분 문자열), `배`(1글자 LIKE) 모두 두 칼럼에 적용된다.
- [ ] Esc: 검색어 있으면 지우기, 없으면 닫기. 바깥 클릭으로 닫힘.

만료
- [ ] 설정에서 텍스트 기간을 24시간으로 바꾸고, 아래 명령으로 한 항목을 이틀 전으로 옮긴 뒤 패널을 다시 열면 그 항목이 보이지 않는다 (조회 시 제외). 앱을 재시작하면 정리되어 행이 사라진다 (`lastPurgeDay` 를 지워 실행 시 정리가 돌게 한다).

```bash
sqlite3 ~/Library/Application\ Support/Paster/paster.sqlite \
  "UPDATE clip_items SET last_copied_at = datetime('now', '-2 days') WHERE id = (SELECT MAX(id) FROM clip_items WHERE kind = 'text' AND pinned_at IS NULL);"
defaults delete com.wjbyun.Paster lastPurgeDay
```

- [ ] Pinned 항목은 같은 조작을 해도 사라지지 않는다.
- [ ] 메뉴의 `업데이트 확인…` 은 회색(비활성)이다 — 플랜 3 에서 연결.
